This root `missions/` folder is archived legacy reference content and is not loaded by current LSOL builds.

Author loose runtime mission packs in `scripts/LSOL_Config/missions`, or package them under `scripts/LSOL_Addons/<package-id>/content/missions`.

The build removes this folder from output. It remains in the repo as reference input for manual migration and historical mission-authoring workflows, especially `tools/migrate-legacy-configs.ps1`.

See `LSOL_Config/missions/README.md` for the active XML mission format and runtime path.
