1. Overview
Implement a new "Hire NPC" mechanism that allows players to automate resource transportation between owned or discovered industries.

2. UI Integration: Office Menu
- Trigger: Add a new button labeled "Hire NPC" to the existing Office Menu.
- Theme: The resulting windows should follow the F8 Menu aesthetic and styling.
- Main Navigation Window: Clicking "Hire NPC" opens a sub-menu with three options:
    - Hire New NPC
    - Manage NPC List
    - Close

3. Functional Requirements
A. "Hire New NPC" Interface
This window facilitates the creation of a new logistics route. It must include the following selection sections:
- Starting Point: A dropdown/list for the player to select the origin industry.
- Destination: A dropdown/list for the player to select the target industry.
- Resource Selection: A list of available resources based on the chosen origin industry.
- Tier Selection: Options to choose between Rookie, Professional, and Veteran drivers.
    - Note: Data for these tiers should be pulled from HiringNPC.ini.
    - Logic Parameters (from .ini):NPCModel: The character model assigned to the driver.
    - NPCCargoLooseRate: Max percentage of cargo lost per journey (e.g., $0.1 = 10\%$).
    - NPCSpeedMultiplier: NPC top speed limit (e.g., $0.9 = 90\%$ of standard speed).
    - NPCPriceMultiplier: Calculation for hiring cost based on resource value (e.g., $50 \times \text{unit price per ton}$).

B. "NPC List" Interface (Management)
This window displays all currently active NPC routes.
- Route List: A scrollable list showing all purchased NPC contracts.
- Management Options: Selecting a specific route opens two secondary actions:
- Fire NPC: Immediately deletes the NPC, their vehicle, and any active cargo.
- Modify NPC: Re-opens the hiring interface for that specific slot, allowing the player to upgrade the driver’s Tier or re-assign the route and resource type.

4. Technical Notes for Implementation
- Ensure the "Modify NPC" function retains previous settings as the default state when the window opens.
- The "Close" button should return the player to the primary Office Menu.
- Check for sufficient funds before confirming the "Hire" or "Modify" (Upgrade) actions based on the NPCPriceMultiplier.

5. Visuals
- Make sure the npc is visible and not something virtual
- Each hired NPC must have a blip so they can be easily visible on the map
